## What To Submit

Return one completed CSV with:

- one row per pair,
- your anonymized `reviewer_id`,
- `winner` set to `A`, `B`, or `tie`,
- integer scores from 1 to 5 for all rubric columns,
- a short rationale.

## Blinding

Each pair contains two artifacts for the same source paper. One artifact was
generated with paper-specific OpenReview feedback. The other was generated
with matched-length unrelated review context. The order is randomized. Please
judge only the artifact quality and do not try to infer the condition.

The condition key is not included in this reviewer-facing index.
