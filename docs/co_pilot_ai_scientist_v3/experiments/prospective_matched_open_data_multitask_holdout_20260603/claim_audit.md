# Claim Audit

| Claim | Status | Evidence |
| --- | --- | --- |
| A prospective matched-budget package can be produced on multiple open-data tasks. | Supported | This package contains 5 sklearn built-in tasks across 5 split seeds (25 paired selections), matched data splits, a co-pilot trajectory, autonomous baseline summary, complete gate log, manuscript, and manifest. |
| The evaluator-stress gate changes branch selection. | Supported | Selection changed in 4 of 25 dataset-split comparisons. |
| The guardrailed selector improves mean test balanced accuracy in this pilot. | Supported | Co-pilot mean 0.923263; autonomous mean 0.920681; delta 0.002582. |
| Co-Pilot AI Scientist v3 outperforms autonomous AI Scientist-v2 generally. | Unsupported | This is an open-data branch-selection pilot, not a full AI Scientist-v2 paper-quality benchmark. |
| Human attention efficiency is measured for this package. | Partially supported | The gate contains complete operator-recorded attention cost, but it is not an independent human-subject measurement. |
