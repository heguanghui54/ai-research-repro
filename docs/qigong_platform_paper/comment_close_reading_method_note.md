# 健身气功短视频评论证据的方法说明

## 1. 资料定位

当前评论资料用于支撑“评论区语境中的传播延异”与“受众再语境化”分析，属于网络民族志与文本近读材料，而不是平台总体频率统计材料。换言之，评论数据可以回答“评论区出现了哪些意义转译方式”，但在现阶段不能回答“这些方式在全平台中占多少比例”。

这一定位与论文主问题一致：短视频平台中的健身气功并非只在视频画面中发生意义滑移，受众还会在评论区通过玩梗、收藏、求指正、功效叙事和跟练反馈等方式继续改写身体文本的意义链条。

## 2. 当前数据状态

- 评论来源：公开短视频评论的匿名化文本。
- 当前规模：263 条非空匿名评论。
- 当前覆盖：59 个正式编码视频，占 120 个编码视频的 49.2%。
- 隐私状态：不保存用户名、用户 ID、头像、主页链接、评论直链等身份字段；评论文本中的 URL 与账号指向已清理。
- 审计结论：隐私与匿名化门槛通过，但评论行数、视频覆盖率、单视频评论数尚未达到正式频率分析门槛。

因此，论文中应将评论材料写作“语境补充证据”或“网络民族志近读证据”，不宜表述为代表性抽样下的统计结论。

## 3. 可使用的分析维度

当前评论近读保留五类较稳的意义信号：

1. 玩梗再语境化：如“笑死”“打卡”等平台话语将严肃功法转入轻量社交表达。
2. 具身延迟：如“收藏”“收藏跟练”等表达显示观看、收藏与真实练习之间的时间差。
3. 标准性争夺：如“标准”“不对”“老师”等表达呈现对动作正误、传授权威与解释权的争夺。
4. 健康焦虑转换：如“颈椎”“失眠”“气血”等表达将健身气功嵌入现代身体焦虑与日常健康叙事。
5. 重新进入练习：如“跟练”“呼吸”“动作”“坚持”等表达显示平台传播并非只有消解，也可能重新导向身体实践。

“商业化疑虑”目前误判率较高，仅保留为后续人工复核方向，暂不作为论文正式分类结论。

## 4. 论文写作边界

建议在论文中这样处理：

> 在评论层面，本文不将匿名评论作为平台总体比例推断的依据，而将其作为网络民族志式的语境材料，用以观察健身气功短视频在受众互动中继续发生的意义转译。评论近读显示，受众并非被动接收功法知识，而是通过玩梗、收藏、求指正、健康经验分享与跟练反馈等方式，将健身气功重新嵌入平台化日常生活。由此，传播延异并不止于视频画面的剪辑和标签，也延伸至评论区的二次阐释与身体实践承诺之中。

必须避免的写法：

- 避免写“评论区用户普遍认为”“大多数用户表现出”等总体性结论。
- 避免把当前词典命中数写成正式比例结论。
- 避免长篇引用评论原文；论文中如需举例，应使用匿名化短引文，并控制数量。

## 5. 后续升级条件

若要把评论材料升级为正式统计分析，至少需要满足：

- 匿名评论不少于 300 条。
- 覆盖正式编码视频不少于 70%。
- 每个纳入评论分析的视频尽量达到 5 条以上评论，无法获取的应记录原因。
- 对词典分类结果进行人工复核，特别是商业化疑虑、健康焦虑等易误判类别。

在当前阶段，评论证据更适合服务论文的“机制解释”和“典型语境展示”，与学生网页人工编码、视频姿态分析、平台元数据共同构成多源证据链。
