# 当前证据边界版研究方法章节

本文件用于把已经完成的工作包转化为可投稿论文的方法学表述。它只写可由当前文件证明的事实；未完成的人工编码、评论补采和视频动作分析不写成研究结果。

## 1 数据来源与样本边界

截至当前工作包，研究共形成 628 条健身气功相关短视频筛选元数据，其中 185 条被判定为可纳入真实平台样本池。已纳入样本的平台分布为：bilibili 147；douyin 31；kuaishou 6；xiaohongshu 1。关键词覆盖情况为：八段锦 26；健身气功 24；导引养生功 16；五禽戏 15；六字诀 15；朋克养生 14；赛博养生 13；肩颈八段锦 13；办公室八段锦 12；程序员八段锦 12；站桩 10；易筋经 8；气功养生 6；太极拳/八段锦 1。

在此样本池基础上，研究已抽取 120 条正式人工编码样本。该编码样本的平台分布为：bilibili 97；douyin 16；kuaishou 6；xiaohongshu 1。由于当前样本明显以哔哩哔哩和抖音为主，小红书、快手样本不足，论文不能做强平台间差异推断；更稳妥的表述是研究“公开可及短视频平台样本中可观察到的意义延异机制”。

Hugging Face 上的 MultiSports、KungfuAthleteBot、TNews、LCSTS、People's Daily NER 等数据集只作为技术校准基线或文本话语基线，不替代真实短视频平台样本。当前 HF/SportsLabKit 校准报告已检查 8 个 HF 数据集，其中 Dataset Viewer 小样本预览通过 0 个；3 个被定位为技术校准数据集，5 个被定位为中文体育/新闻语言基线。它们可说明动作定位、姿态可见性、体育/新闻文本处理等工具链是否可运行，却不能单独支持“短视频平台传播延异”的经验结论。

## 2 人工编码流程

正式编码表当前包含 120 行，但已完成且可计为人工编码的行数为 0。研究已生成中文人工编码手册、LLM 预填复核表、编码员任务表和双编码子样本任务表。LLM 预填仅作为人工判断提示，不作为正式编码结果。

为防止自动预填被误判为人工结果，正式审计已经加入 `human_coder_id_required` 规则。以 LLM 预填表作为 formal 编码表审计时，审计计数为 pass=6、warn=0、fail=2，说明其不能直接进入正式结果分析。

正式论文只有在 120 行人工编码通过 `audit_qigong_coding_values.py --profile formal`，且 20% 以上双编码子样本完成一致性分析后，才能报告意义框架分布、影像化规训变量分布和编码可靠性。

## 3 LLM 辅助语义编码

当前已有 120 条 LLM 语义编码记录。公共方法文字只报告具体模型名称；当前记录中的模型为：deepseek-chat。LLM 语义编码可用于形成低置信度复核队列、辅助识别传播延异路径、生成候选解释线索，但不能替代人工编码和双编码可靠性。

LLM 语义编码的正式使用条件包括：记录具体模型名、提示词版本和置信度；保留 low-confidence/unknown 复核队列；完成随机抽查或人工一致性比较；在论文中明确其为辅助编码工具。任何模型接入方式、端点或私有 API 细节都不进入论文正文。

## 4 评论语境层

当前正式评论文件包含 263 行，其中有文本的匿名评论为 263 行，覆盖 59 个正式样本视频。评论补采目标表已经生成，按每个样本视频至少 5 条评论估算，仍需补采 447 条匿名公开评论。其中 59 个视频属于 `P1_top_up_to_five`，61 个视频属于 `P2_mark_unavailable_or_find_alternative`。

评论审计计数为 pass=6、warn=0、fail=3。当前隐私字段、匿名化状态、文本标识符扫描和评论 ID 唯一性均通过审计，但评论总量、正式样本覆盖率和单视频评论数仍未通过正式频率分析门槛。

因此，当前评论材料不能支持“收藏等于练过”“功德+1”“权威争夺”等现象的频率结论，也不能用于平台间评论心理结构比较。不过，研究已生成匿名近读案例和补采目标表。这些材料可用于网络民族志式语境近读、机制解释和编码手册修订，但必须明确为质性例证；只有评论审计通过后，才能进入频率描述或组间比较。

## 7 建议替换到稿件中的方法表述

本文采用“真实平台样本-人工编码-LLM 辅助语义编码-匿名评论语境-典型视频身体证据”的分层方法。首先，依据平台、关键词和公开可见性建立 628 条健身气功相关短视频筛选记录，并在不绕过访问控制、不保存可识别个人信息的原则下形成 185 条可纳入平台样本池。其次，从样本池中抽取 120 条正式编码样本，依据中文人工编码手册对主导意义框架、身体可见性、动作节奏、平台踪迹、影像痕迹强度、媒介时间性和具身消解程度等变量进行人工编码，并设置不少于 20% 的双编码一致性检验。再次，将标题、标签、公开互动指标和匿名评论摘要组织为视频语义包，使用 `deepseek-chat` 等具体模型进行辅助语义编码，模型输出仅用于生成复核线索和低置信度队列，不直接作为正式结论。最后，在权利确认的前提下选取 3-5 个典型视频，使用 SportsLabKit 或 OpenCV/MediaPipe 后备链路提取身体可见性、动作连续性、运动能量和节奏变化等指标，用以辅助解释短视频影像化规训如何影响健身气功的具身经验。
