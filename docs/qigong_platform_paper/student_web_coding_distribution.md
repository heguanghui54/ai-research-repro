# 学生网页人工编码分工说明

用途：发给参与人工编码的学生或用于教师组织填报。本文档不放学生访问口令；访问口令由教师单独发送。

## 学生需要做什么

每名学生使用自己的编号登录网页人工编码平台，逐条完成系统分配的视频任务。每条任务必须先点击“打开视频”，看过标题、标签、画面、字幕/口令、动作节奏和可见平台语境后再填写。

不能只看标题填写，也不能照抄 LLM 辅助建议。证据不足时选择“无法判断”，并在备注里说明“视频打不开”“画面不足”“字幕/标签不可见”等。

## 每条视频必须填写

- 主导身体框架
- 身体可见性
- 出镜人数
- 动作节奏
- 镜头关系
- 文字遮挡
- 呼吸提示
- 意念/放松提示
- 气/经络提示
- 风险/禁忌提示
- 行动号召
- 平台踪迹
- 来源/正统性引用
- 平台补充方式
- 二元反转/张力结构
- 再语境化场景
- 可视性中心化
- 节奏规训
- 功效标签化
- 影像痕迹强度
- 媒介时间性
- 赛博养生符号
- 玩梗密度
- 具身消解
- 证据标记和备注

## 备注怎么写

备注只写匿名化观察，不写用户名、主页、手机号、评论者身份或原始链接。

推荐写法：

- `口令跟练;全身可见;字幕提示呼吸`
- `标题强调肩颈舒缓;热歌快剪;动作片段化`
- `看不到完整动作;只能判断上半身`
- `视频链接无法打开;暂缓编码`

## 教师导出与审计

学生提交后，教师使用本地导出脚本从 Supabase 导出编码结果，并生成 CSV、JSON 和 Markdown 审计摘要。正式论文结果只使用通过完整性审计和复核一致性检验的数据。
