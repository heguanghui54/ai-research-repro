5. 如果换成其他 agent，它们会怎样试？

下面是教学推演，不是本次真实运行结果。它的作用是帮你理解“搜索算法差异”： 同一道任务，不同 agent 可能会选择不同的试错路线。

Agent 面对因果任务可能试什么 面对公平任务可能试什么 它的搜索味道
AI Scientist v2 先试一个较完整的方案，例如集成多个回归器、标准化特征，再根据验证误差继续改。 先试去相关、约束优化、后处理阈值等多种公平机器学习办法。 像写实验日志的树搜索：保留有希望的方向，继续深挖。
Autoresearch 如果“加 Ridge 正则化”让 MAE 下降，就沿着这个方向继续小调参数。 如果“调分类阈值”让群体差距变小，就继续围绕阈值和权重微调。 像贪心爬山：只保留眼前更好的改法。
AIDE 可能同时保留“线性模型”“集成模型”“更强正则化”几个候选，并修复报错分支。 遇到 Fairlearn API 报错时，会更重视把这条分支修到能跑，再比较分数。 像多份草稿 + 修 bug：让更多实验有效完成。
OpenEvolve 让很多候选方案同时变异：有的换模型，有的换损失，有的换数据切分。 同时保留多种公平策略，例如预处理、训练中约束、预测后调阈值。 像进化比赛：保留一群方案，让它们竞争和变异。
